# Project instructions

- Work on this site locally only. Do not upload or publish it through Sites or any other hosting service, including private hosting.
- Use a local preview for development and verification.
- Follow `KRUISPUNTEN.md` when creating or changing junction drawings; verify the shared renderer and all eight rotations with `node test.mjs` and a local visual check.
- Write “Markdown” with a capital M when referring to the markup language.
- When generating a commit message from open changes, use `type(subject): details`.
